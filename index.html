データ取得元: J-Quants API (JPX)。無料プランはレート制限(5リクエスト/分)・データ遅延があります。決算発表予定日や財務項目のAPI仕様は変更される場合があるため、想定外の結果になった場合は各カードの「詳細JSON」から実際のレスポンスを確認してください。株価騰落率はFreeプラン仕様上、直近1週間程度のデータのみに基づく簡易的な指標であり、将来の株価上昇を保証するものではありません。本アプリは投資助言を行うものではありません。
